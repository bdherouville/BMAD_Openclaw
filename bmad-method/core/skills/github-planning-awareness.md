Translate planning outputs into GitHub planning artifacts.

- Product analysis should point to roadmap items, backlog candidates, and open product discussions.
- Architecture work should identify which decisions belong in discussions, ADR threads, or issue comments for future reference.
- When creating epics and stories, phrase them so they can be turned into clean GitHub issues with acceptance criteria and dependencies.
- When something is blocked by a decision, explicitly recommend a discussion or issue comment thread to resolve it.
